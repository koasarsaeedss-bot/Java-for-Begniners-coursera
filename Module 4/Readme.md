# ☕ Java Programming for Beginners – Module 4
This folder contains my practice work and learning materials from **Module 4 of the Java Programming for Beginners course by IBM on Coursera**.
## 📚 Topics Covered
In this module, I learned how to handle errors and exceptions in Java programs.
### Topics included:
* **Exceptions and Errors**
* Exceptions disrupt normal program flow but allow graceful error handling
* Errors signal critical issues beyond the programmer's control
* **Types of Exceptions**
* Checked exceptions (checked at compile-time)
* Unchecked exceptions (not checked at compile-time)
* **Custom Exception Classes**
* Extending Exception for checked exceptions
* Extending RuntimeException for unchecked exceptions
* **Exception Handling**
* try block
* catch block
* finally block
* Multiple catch blocks
* **The throws Keyword**
* Better error handling and separation of concerns
* **Best Practices for finally**
* Always execute cleanup code, such as releasing database connections
* Avoid return statements and unhandled exceptions
## 💻 Lab Work
The module includes hands-on programming exercises, including:
* Writing **try-catch-finally** blocks
* Handling **checked and unchecked exceptions**
* Creating **custom exception classes**
* Using **multiple catch blocks**
* Applying the **throws** keyword
* Following **best practices** for cleanup code in finally blocks
